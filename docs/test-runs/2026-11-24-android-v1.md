# Version 1 Android manual QA run — 2026-11-24

**Build under test** — `b015e80f47782c117ba355f2748023ea797a7171` (Step 2, “Build synthetic mobile feed and recovery harness”).

**Decision** — **BLOCKED / NOT READY** for Android. **0 Pass, 0 Fail, 12 Blocked.** The [release gate](../risk-and-traceability.md#release-risks-and-gate) requires device evidence. No product defect was verified.

**Attempted environment** — Linux x86_64 workspace, Android Emulator 37.4.2.0 in software mode, ADB Platform Tools 37.0.3. The attempted targets were the Harbor35 Android 15 (API 35) x86_64 AVD and the Harbor30 Android 11 (API 30) x86_64 AVD. The build and target recorded here apply to all cases. Network conditions in the table are planned and were never exercised on a mobile target.

## Environment investigation

- Recreated Harbor35 and retried with no snapshots and software emulation. The workspace has no `/dev/kvm`, and `emulator -accel-check` reported that KVM requires CPU VMX or SVM support. ADB reported `device offline` repeatedly before the emulator process terminated. Android boot completion was never observed.
- Retried on Harbor30 using a complete Android 11 image stored outside the temporary filesystem. ADB repeatedly reported `device offline` and later failed to return a boot-complete value. The emulator terminated before app installation.
- A separate native-build attempt with the generated Gradle 9.3.1 wrapper and OpenJDK 21 failed during Gradle configuration on `JvmVendorSpec.IBM_SEMERU`. This is a toolchain compatibility failure involving the Foojay resolver, before APK assembly. See the [upstream compatibility issue](https://github.com/react/react-native/issues/55781). A scratch-only override to Foojay 1.0.0 got past that error and provisioned JDK 17. It did not supply an installable build for this device run.
- No authorized physical Android device was available. iOS status is **Not Run — macOS/Xcode runtime unavailable in this workspace**. This decision covers Android only.

Install, launch, feed access, app-scoped Logcat, background/resume, and force-stop/relaunch could not be verified.
